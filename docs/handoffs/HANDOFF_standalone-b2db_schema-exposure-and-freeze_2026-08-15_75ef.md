## Key Decisions

**Chosen: pin `schema`'s profile to the root-owned config; no caller `--profile`.**
Rejected: accepting a caller flag. An arbitrary profile lets a caller enumerate
the shape of profiles the boundary is not configured for. agy independently
confirmed the pinning is uncircumventable, and found that `purge_ambient_env()`
scrubs `SECRETSPEC_*` before dispatch as a second layer.

**Chosen: leave `Secrets::config()` as unconditional `#[doc(hidden)] pub`.**
Rejected: gating it behind a narrow cargo feature. The `manifest-edit`
precedent (`manifest-edit = ["dep:toml_edit"]`, `cli = ["manifest-edit"]`)
exists to keep a DEPENDENCY out of a root-privileged binary. `config()` is a
getter returning an already-public type and pulls in zero dependencies, so a
feature would gate nothing. `pub(crate)` was never an option — the broker is a
separate crate. Reasoning is recorded in `0a17ce0`'s commit message so it does
not get re-litigated.

**Chosen: correct the docs about descriptions rather than emit them.**
Rejected: changing `codegen.rs::property_type` to emit `description`. That is
UPSTREAM code consumed by every SDK; changing it is fork divergence paid for on
the next merge forward. It belongs in a PR to `cachix/secretspec`.

**Chosen: install the skill as a symlink** (`~/.claude/skills/sudo-secretspec`
-> the repo path). Rejected: a copy. The repo stays the single source of truth
and edits need no reinstall. Matches how `herdr` and `composio-cli` are
installed. Caveat: resolves only on this machine.

**Chosen: point the skill's doctor guidance at each finding's `advisory` field.**
Rejected: listing the current six advisory code names. The old text hardcoded
two names and there are now six; naming the current six would have earned the
same staleness a third time.

### Gotchas that cost real time

- **Every lifecycle subcommand authenticates, even `--dry-run`.** The `sudo`
  re-exec happens before the flag is considered, under `timestamp_timeout=0`.
  Never put one in an unattended loop.
- **`check` reports to STDERR; `export` writes name->value JSON to STDOUT.**
  Never print `export` output — parse and assert on keys.
- **`template-check` is a RAW BYTE comparison.** Formatting changes are drift.
- **`install --declarations` does NOT prune.** `undeclare` is the cleanup route.
- **A first prompt to a Cursor pane in a never-trusted workspace gets eaten** by
  the trust modal, and the agent still reports `idle`. Read the pane and resend.
- **`herdr agent read` cannot recover alternate-screen output.** More `--lines`
  will not help. Have the agent write Markdown to a file and read that.
